Comparativo entre processos de vendas

Cada linha é um processo, contado a partir do dia 1 (início dele). Assim dá para ver se o processo atual está acima ou abaixo dos anteriores no mesmo ponto do calendário de vendas. Conta só matrículas do Acelerador (sem o Topo).

 

Como ler: passe o mouse (ou o dedo) no gráfico para ver o valor de cada processo naquele dia. Linha mais alta = mais matrículas acumuladas no mesmo dia do processo. O processo atual (linha grossa) só vai até hoje.
